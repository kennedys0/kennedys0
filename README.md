# FEKOJEWAN

**Independent builder · AI-assisted development · Web & API security**

I like turning rough ideas into working software — from useful tools to slightly unusual experiments.

Some call it *vibe coding*. For me, the interesting part starts after the first prompt: understanding what was generated, making deliberate design choices, testing the edges, and knowing when something is actually ready.

### What I'm exploring

- **Product & frontend** — interfaces that are clear, responsive, and pleasant to use.
- **Developer tooling** — reusable skills, workflows, and automation that make building easier.
- **Security** — practical Web and API research, with responsible disclosure in mind.
- **On-chain experiments** — small explorations in contracts, generative art, and interactive experiences.

### How I build

**Start small.** Get the core flow working before adding complexity.  
**Use AI deliberately.** Faster iteration is useful; unreviewed output isn't.  
**Care about the details.** Copy, loading states, accessibility, and mobile layouts all matter.  
**Test what matters.** A convincing demo isn't the same as a reliable product.
